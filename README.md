# Mohammed Sohail Portfolio

A custom portfolio website for Mohammed Sohail, a 4th-year cybersecurity student at Jeppiaar University exploring AI, agentic systems, and security engineering.

Live site: [mohammed-sohail-portfolio.netlify.app](http://mohammed-sohail-portfolio.netlify.app)

## Stack

- HTML
- CSS
- JavaScript
- Netlify Forms

## Highlights

- Anime-inspired cyber hero section
- Interactive motion and network background
- Project showcase for AI + cybersecurity work
- Contact form powered by Netlify
- Mobile-friendly single-page layout

## Local preview

You can open `index.html` directly, or run a simple local server:

```powershell
python -m http.server 4173
```

Then visit `http://127.0.0.1:4173`.

## Project structure

- `index.html` - main page markup
- `styles.css` - visual design and responsive layout
- `script.js` - animations and interactions
- `success.html` - contact form success page
- `assets/` - profile artwork and static assets
- `netlify.toml` - Netlify config
